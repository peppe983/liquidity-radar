모든 탭 상단에 고정되는 헤더와 탭 4개, 그리고 차트 위 기간 선택 칩.

- 제공할 것: 기준일, 갱신 시각(KST), 출처 문자열, 현재 탭.
- 탭은 요약 · 수위 · 압력 · 알아두기 순서 고정. 선택 탭은 `ink` 글자 + 2px `ink` 밑줄.
- 기간 선택은 `lr-chips` 그룹(6개월 · 1년 · 3년, 기본 1년). 선택 칩은 `ink` 채움에 `ink-inverse` 글자. 요약 탭에는 넣지 않고 차트가 있는 탭의 차트 위 한 줄에 둔다.
- 모바일에서는 메타 줄이 줄바꿈되고 탭 줄만 가로 스크롤된다.
- 마크는 레이더 호 세 개를 그린 임시 기호다. 정식 로고가 생기면 교체한다.
