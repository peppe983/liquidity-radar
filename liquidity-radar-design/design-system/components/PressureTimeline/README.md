최근 3년의 압력 단계를 가로로 긴 띠 하나에 날짜별로 칠한다.

- 제공할 것: 날짜별 단계 배열(L0~L3), 기간 시작·끝.
- L0은 얇은 `pressure-0` 바탕 띠. L1~L3은 `pressure-1~3` 색과 **높이**(짧게 → 길게)로 함께 구분한다. 색만으로 단계를 전달하지 않는다.
- 마우스를 올리면 세로 크로스헤어(`ink` 1px)와 툴팁(날짜, 단계). 이 크로스헤어·툴팁 패턴을 모든 차트에 똑같이 쓴다.
- 오른쪽 끝에 "지금 L0" 표시.
- 시안의 날짜별 단계는 예시다. 구현에서는 `history.json`에서 읽는다.
