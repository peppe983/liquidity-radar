압력 탭 전체 시안. "부족해지고 있나". 하위 칩 4개: 금리 두 개 · SOFR − IORB · SRF 사용액 · 종합 판정.

- 툴바 오른쪽 `S&P 500 비교` 토글: 금리·스프레드·SRF 차트 아래에 S&P 500 띠(기간 시작=100)를 같은 x축·크로스헤어로 붙인다. 시안은 켜진 상태로 연다.
- 종합 판정에는 기간 선택과 토글이 필요 없어 숨긴다.
- 스프레드 차트의 가로선 +5 / +15 / +30bp는 `pressure-1~3` 색으로 압력 단계와 연결한다.
- 종합 판정표의 칸 중 브리프에 없는 조합(L0·L1 행의 늘어남/보합 등)은 시안용 예시다. 실제 판정 규칙으로 교체한다.
