수위 탭 전체 시안. "물이 얼마나 있나". 하위 칩 7개로 차트를 하나씩 고르고, 기간(6개월 · 1년 · 3년)은 모든 차트에 적용된다.

- 구조: 탭 소개 한 줄 → 툴바(하위 칩 + 기간) → 차트 카드(제목, 질문 한 줄, 계산식 블록, 차트) → 해설 카드 3개(무엇인가 / 어떻게 읽나 / 주의).
- 툴바 오른쪽 `S&P 500 비교` 토글을 켜면 차트 아래에 S&P 500 띠(기간 시작=100)가 같은 x축·크로스헤어로 붙는다. y축을 겹치지 않으려고 별도 띠로 둔다. "네 지표 한눈에"와 "주가와 비교"에서는 비활성. 시안은 켜진 상태로 연다.
- 차트는 `window.LiquidityRadar.chart`로 그린다. Net Liquidity 차트에는 크로스헤어·툴팁이 열린 상태로 보인다.
- 수치는 예시 데이터(`LiquidityRadar.demo`)이며 브리프의 현재값·범위에 맞춰 만들었다. 구현에서는 `history.json`에서 읽는다.
