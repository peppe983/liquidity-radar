상태 5단계(양호 · 중립 · 주의 · 경고 · 위험) 배지. 항상 색 + 아이콘 + 글자를 함께 쓴다.

- 제공할 것: 단계 하나. 클래스 `lr-badge lr-badge--good|neutral|caution|warning|danger`, 크게는 `lr-badge--lg`.
- 아이콘 모양이 단계마다 다르다(원·체크, 원·가로선, 삼각형, 마름모, 팔각형). 색각 이상에서도 모양으로 구분된다.
- 바탕은 `status-*-soft`, 글자·아이콘은 `status-*`.
- 하지 말 것: 상태 색을 차트 시리즈에 쓰기, 아이콘 없이 색점만 쓰기, "매수" 같은 행동 문구 넣기.
