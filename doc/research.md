## 3. 핵심 개념 정리

### 3.1 연준 대차대조표의 구조

연준이 자산을 사면 같은 크기의 부채가 생긴다. **중요한 건 그 부채가 어느 칸에 담기느냐.**

```
[ 자산 = WALCL ]  =  [ 지급준비금 | 유통화폐 | 기타 | TGA | RRP ]
```

| 칸 | 주인 | 성격 |
|---|---|---|
| 지급준비금 | 은행 | 은행이 굴릴 수 있는 실탄 → **유동성** |
| 유통화폐 | 민간 | 지갑·ATM 속 현금 |
| TGA | 정부 | 정부 금고. 은행 시스템 밖 |
| RRP | MMF 등 | 연준에 주차된 돈 |

### 3.2 Net Liquidity 공식

```
Net Liquidity = WALCL − TGA − RRP
```

= 전체에서 **연준에 묶인 두 칸을 잘라낸 나머지**

> ⚠️ 단위 주의: WALCL·WTREGEN은 백만 달러, RRPONTSYD는 십억 달러. 조 달러로 정규화 필수.
> ⚠️ FRED CSV의 결측은 과거엔 `.` 표기였으나, 실제 라이브 엔드포인트 확인 결과 빈 문자열로도
>   온다 (1단계 구현 중 실측). `na_values=[".", ""]`로 둘 다 방어적으로 처리 필요.

### 3.3 자주 하는 오해 (직접 헷갈렸던 지점들)

**오해 1: "지준은 연준에 묶여 있으니 안 도는 돈이다"**
→ 지준은 원래 연준 장부를 떠날 수 없다. 은행 A가 B에게 보내면 계좌 주인만 바뀐다.
   "위치"가 아니라 "누가 그 돈으로 뭘 할 수 있나"가 기준.
   지준 주인은 은행 → 대출·국채 매입·딜러 자금 공급 가능. TGA는 정부, RRP는 묶인 돈.
→ 참고: 미국 지급준비율은 2020년 3월 26일부로 **0%**. 의무가 아니라 은행이 원해서 두는 것 (IORB 이자, 규제 대응).

**오해 2: "지준이 줄면 돈이 풀린 것이다"**
→ 반대. 은행이 자산을 사도 지준 총액은 불변(주인만 이동).
   지준 총액이 변하는 건 **연준 부채 칸 사이 이동**뿐:
   - 감소: QT, TGA 충전, RRP 유입, 현금 수요 증가 → **유동성 위축**
   - 증가: QE, 정부 지출, RRP 이탈 → **유동성 개선**
→ "은행이 돈을 굴리는가"는 지준이 아니라 대출 잔고·신용 증가율로 봐야 한다.

**오해 3: "실물 투자나 수입 대금으로 돈이 빠져나간다"**
→ 돈은 은행 계좌 사이를 옮길 뿐 시스템을 떠나지 않는다.
   달러는 미국 은행 계좌에만 존재 가능 (해외 은행도 코레스 계좌 필요).
   실제로 시스템을 떠나는 경우는 셋뿐: 지폐 인출 / TGA 유입 / RRP 유입.

**오해 4: "연준이 국채를 사면 돈이 재무부로 간다"**
→ 연준은 재무부에서 직접 못 산다(법적 금지, 재정 화폐화 방지). 유통시장에서 민간에게서 산다.

| | 신규 발행 (재무부가 팖) | QE (연준이 삼) |
|---|---|---|
| 지준 | 감소 | 증가 |
| TGA | 증가 | 변화 없음 |
| 연준 자산 | 변화 없음 | 증가 |
| 유동성 | 위축 | 공급 |

**오해 5: "SRF 금리는 시장금리보다 높으니 기준금리가 아니다"**
→ 미국 기준금리는 단일값이 아닌 **범위**. 연준은 floor system으로 시장금리를 범위 **안쪽**에 둔다.
   SRF 최저입찰금리 = 목표범위 **상단** (FOMC가 정하고 implementation note에 명시).
   일부러 비싸게 설정 → 평상시 아무도 안 씀.

```
목표범위 상단 ─ SRF 최저입찰금리, 재할인율
              ─ IORB
              ─ SOFR, EFFR (평상시 여기)
목표범위 하단 ─ ON RRP 금리
```

### 3.4 TGA/RRP 시소 메커니즘

국채 발행 대금이 **어디서 나오느냐**가 시장 충격을 가른다.

| 경로 | 흐름 | 지준 영향 |
|---|---|---|
| A: MMF가 RRP 자금으로 T-bill 매입 | RRP ↓ → TGA ↑ | **없음** (완충 작동) |
| B: 은행·투자자가 예금으로 매입 | 지준 ↓ → TGA ↑ | **직격** |

이것이 2022~2026년을 설명한다. QT로 2.14조를 줄이는 동안 RRP에서 2.37조가 빠져나와 상쇄 → 순유동성 거의 불변, S&P 500 +78%.

**→ 그 완충이 소진된 현재는 경로 B만 남는다.** 같은 규모의 발행·QT가 이제 지준을 직접 깎는다.

판단 로직으로 직결:

| 관찰 | 해석 |
|---|---|
| TGA ↑, RRP ↓, 지준 유지 | 완충 작동, 충격 작음 |
| TGA ↑, 지준 ↓ | **실질 유동성 흡수, 경계** |
| TGA ↓, 지준 ↑ | 정부 지출로 유동성 공급 |

기존 공식은 TGA·RRP를 똑같이 빼기만 해서 이 차이를 못 잡는다.

## 4. 지표 체계 (2층 구조)

수량 지표만으로는 "지금 수위가 충분한가"에 답할 수 없다. **가격은 수량보다 먼저 반응한다.**

### 수량 지표 — 물이 얼마나 있나

| FRED 코드 | 내용 | 비고 |
|---|---|---|
| `WALCL` | 연준 총자산 | 주간(목) |
| `WTREGEN` | TGA | 주간 (⚠️ 원래 "영업일"로 기술했으나 1단계 구현 중 실측 결과 실제로는 약 7일 간격 주간 시리즈로 확인됨) |
| `RRPONTSYD` | ON RRP | 영업일 |
| `WRESBAL` | **지급준비금** | 유통화폐 노이즈 없음, 더 정직 |
| `TREAST` | 연준 보유 국채 | QT/QE 실측 |
| `WSHOMCB` | 연준 보유 MBS | 감소 훨씬 느림 (조기상환 의존) |
| `WSHOSHO` | 국채 중 단기물 | 만기 구성 변화 |

지준 표시 방식 3종: **명목값 / 인플레이션 조정값(÷CPI) / 지준÷은행총자산**
- 은행 총자산: `TLAACBW027SBOG` 등
- 절대 금액만으로는 충분한지 알 수 없음 (LCLoR 개념 — 추정만 가능)

### 압력 지표 — 부족해지고 있다는 신호

| 지표 | 의미 | 주기 |
|---|---|---|
| **SOFR − IORB** | 담보시장 압력. 조기 경보 | 매일 |
| **EFFR − IORB** | 은행 본체 지준 부족. 더 심각 | 매일 |
| **SRF 사용량** | 민간 조달 실패. 0 이탈 자체가 신호 | 매일 |

경고 단계:
1. SOFR − IORB 확대 → 딜러 여력 부족
2. SOFR 급등 지속 → 지준 희소성 의심
3. EFFR − IORB 확대 → 은행 본체 부족, 심각
4. SRF 사용 발생 → 조달 실패

> SRF는 **낙인 효과(stigma)** 때문에 사용액 0이어도 압력이 없다는 뜻은 아님. 스프레드 병행 필수.

### 보조 지표
- `DTWEXBGS`(Nominal Broad U.S. Dollar Index) — 유로달러 사각지대 간접 포착 (달러 강세 = 해외 달러 부족).
  ⚠️ `DXY`는 FRED에 존재하지 않는 시리즈 ID (404 확인, 1단계 구현 중 실측). ICE Dollar Index가
  아니라 이 시리즈로 대체.
- `DFII10` — 자금 조달 비용 (양이 많아도 비싸면 위험자산에 안 감)

### 시장 vs 시장 구분
| | SOFR (레포) | EFFR (연방기금) |
|---|---|---|
| 담보 | 있음 | 무담보 |
| 참여자 | 딜러·헤지펀드·MMF·은행 등 광범위 | 매우 제한적 (주로 FHLB → 은행) |
| 규모 | 하루 수조 달러 | 수백억 달러 |
| 특이점 | 자금시장 본체 | FHLB는 IORB 못 받아 EFFR < IORB가 정상 |

## 5. 지표의 한계

| # | 한계 | 대응 |
|---|---|---|
| 1 | **유통화폐 혼입** — 항상 과대평가 | WRESBAL 병기, 변화량 중심 해석 |
| 2 | **유로달러 사각지대** — 해외 달러 신용 전혀 안 잡힘 (교정 불가) | DXY 보조 |
| 3 | **신용 창출 미포착** — 대출 급증해도 지준 불변 | 대출 잔고·신용 증가율 별도 패널 |
| 4 | **관계 불안정** — 위험자산 선행성이 국면 따라 깨짐 | 예측 아닌 환경 설명으로 포지셔닝 |
| 5 | **체제 변화** — 같은 공식도 국면 따라 의미가 달라짐 | 절대 임계값 대신 Z-score + 기간 선택 |

### 한계 4 상세
선행 기간 추정치가 출처마다 다르다(0~8주, 2~6주 등) — 관계의 불안정성 자체를 보여준다.
깨지는 경우: 위기 국면(유동성 공급 = 위기 심각 신호), 실적·금리 주도 장세, 사후 해석의 함정.

### 이 지표의 올바른 위치

| 할 수 있는 것 | 할 수 없는 것 |
|---|---|
| 달러 유동성 방향 파악 | 자산 가격 예측 |
| 자금시장 스트레스 조기 감지 | 진입·청산 타이밍 |
| 정책 이벤트 영향 추적 | 해외·신용 경로 포착 |
| 위험 선호 환경 판단 | 단독 의사결정 |

**체제 게이지지 전략이 아니다.** 날씨 예보에 가까움.

## 6. 설계 요구사항 (개념 정리에서 도출)

1. **발표 주기 불일치 처리** — WALCL·TGA(WTREGEN) 주간, RRP 영업일. `reindex` + `ffill`
2. **갱신 타이밍** — H.4.1 목요일 21:30 UTC 발표 → cron은 22:00 UTC
3. **대시보드 2구역 구성**
   - 상단 "수위" 패널: Net Liquidity, WRESBAL 추이와 변화량
   - 하단 "경고등" 패널: 스프레드 이탈 여부, SRF 사용
4. **종합 판단 로직 (압력 우선)**
   - 수량 ↑ + 압력 없음 → 양호
   - 수량 ↓ + 압력 없음 → 중립
   - **압력 신호 발생 → 수량 무관하게 경고**
5. **유동성 변화 요인 분해** — 원인이 QT인지(TREAST↓) TGA 충전인지(WTREGEN↑) 구분해 표시
6. **QT/QE 실측** — TREAST·WSHOMCB 4주 변화량. 만기가 월 중순·말일에 몰려 주간 데이터는 들쭉날쭉 → 이동평균 필수. FOMC 발표 한도 vs 실제 감소분 격차 비교
7. **한계 고지를 대시보드에 명시** — 숨기지 말고 드러낼 것
8. **Z-score + 기간 선택(2M/6M/1Y/2Y)** — 체제 변화 대응

## 7. 우리 시스템의 차별점

기존 트래커 대부분이 "수치와 차트"에서 끝난다. 우리가 더할 것:

1. **뉴스 → 유동성 영향 자동 분석.** 연준/재무부/QT/부채한도 뉴스를 방향·강도·근거로 분류, 주간/월간 리포트
2. **수치와 뉴스의 결합 해설.** "왜 이렇게 움직였는가"를 이벤트와 연결
3. **대화형 탐색.** MCP 서버로 자연어 질의
4. **요인 분해.** 연준발인지 재무부발인지 구분

뉴스 규칙 예시: QRA에서 **단기물 위주 발행 → RRP 흡수 가능성** / **중장기물 위주 → 지준 직격 가능성**
